# Dragons-Flight
Dragon's Flight - Classic Reimagined arcade game built with Python and Pygame

## 🎮 Game Features

- 🐉 Dragon flight gameplay
- 🏰 Castle tower obstacles
- 💎 Gem collection
- ❤️ 3-heart health system
- ⭐ Score and High Score
- 📈 Multiple levels
- 🔥 Fireball attacks
- 👹 Dark Dragon boss battle
- ⏸️ Pause system
- 🏆 Victory and Game Over screens
- 🔊 Sound effects

## 🎯 Controls

- **SPACE** — Fly / Flap
- **F** — Fireball during Boss Battle
- **P** — Pause / Resume
- **R** — Restart after Game Over or Victory

## 🗺️ Levels

### Level 1 — Enchanted Forest
Survive the castle obstacles and collect gems.

### Level 2 — Cursed Castle
Obstacles become faster and the gaps become smaller.

### Level 3 — Lava Fortress
The challenge becomes even harder.

### Boss Battle — Dark Dragon
Defeat the Dark Dragon using fireballs before losing all your hearts.
